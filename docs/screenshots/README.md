## 📷 Guidelines for Capturing New Screenshots

When updating or adding visual previews:

1. **Resolution**: Minimum width of 1280px for desktop previews, 390px for mobile previews.
2. **Authenticity**: Capture from live builds or local development runs; never use simulated mockups or non-code vector renders.
3. **Naming Convention**: Use sequential numerical prefixes: `[0-9]{2}-[kebab-case-name].png` (e.g. `05-mobile-language-modal.png`).
4. **Theme Representation**: Include both high-contrast Dark Mode and Warm Ivory Light Mode captures to demonstrate accessible theming.
